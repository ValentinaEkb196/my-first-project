# Charm Parfume

Лендинг аромастилиста **Charm Parfume** — авторские композиции по мотивам мировых шедевров с индивидуальным подбором.

## Возможности

- Приветственный лендинг с секциями: герой, об эксперте, преимущества, линейки, каталог, квиз, отзывы, FAQ, контакты
- Фильтрация каталога по категориям (Классика / Селектив / Премиум)
- Интерактивный квиз подбора аромата (3 вопроса)
- Модальное окно с подробностями о каждом аромате
- Форма заявки с валидацией (данные сохраняются в `localStorage`)
- Переключение светлой и тёмной темы
- Адаптивная вёрстка и мобильное меню

## Структура проекта

## Быстрый старт

### Вариант 1 — просто открыть файл

Откройте `index.html` в браузере двойным кликом.

### Вариант 2 — локальный сервер

```bash
npm install
npm start
```

Сайт будет доступен по адресу [http://localhost:3000](http://localhost:3000).

## Технологии

- HTML5, CSS3 (CSS-переменные, Grid, Flexbox)
- Vanilla JavaScript (без фреймворков)
- Google Fonts: Cormorant Garamond, Inter
